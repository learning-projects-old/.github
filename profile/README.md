# Isanin Learning Archive

📚 Учебные проекты, эксперименты и ранние версии приложений.

Коллекция учебных работ и прежних реализаций. Здесь можно посмотреть отдельные подходы, интерфейсы и эксперименты, выполненные при изучении веб-разработки.

## 🧭 Направления

| Направление | Назначение |
|---|---|
| ⚛️ Веб-разработка | Учебные проекты и упражнения на React, Vue и TypeScript. |
| 🎨 Интерфейсы | Портфолио, страницы и небольшие пользовательские приложения. |
| 🧪 Эксперименты | Отдельные решения для проверки идей и изучения технологий. |
| 🗂️ История | Ранние версии приложений и результаты учебных заданий. |

## 🔄 Как устроена работа

1. Выбрать работу по интересующей технологии или задаче.
2. Прочитать README и проверить требования к окружению.
3. Изучить код и историю изменений.
4. Перед повторным использованием проверить зависимости и применимость решения.

## 🚀 С чего начать

Начните с небольшого проекта по знакомой теме. Для звука и интерфейса подойдёт ambient-mood, для настройки терминала — powershell-profile.

## 📌 О материалах

Назначение организации — хранение учебных работ. Название архива не означает, что каждый репозиторий переведён в режим GitHub Archive; статус нужно смотреть на странице проекта.

Часть проектов доступна только участникам организации. Инструкции запуска,
требования и ограничения проверяйте в README выбранного репозитория.
